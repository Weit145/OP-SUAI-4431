**Полный перенос остальных диаграмм в Process Modeler не завершён.** Пакетный XML-импорт выявил ошибки. Экспериментальные файлы исключены из итогового архива. Остальные схемы редактируются в `исходники/ЛР3_Смарт-коворкинг.drawio`; SVG и PNG находятся в `исходники/диаграммы`. Это не собственные проекты Process Modeler. Файла ERwin Data Modeler для IDEF1X нет.

## Воспроизведение

На Windows: Python с Pillow, затем `исходники/diagrams.py` и `исходники/report.py`. Для содержания и PDF используется установленный Word и `инструменты/export-word.ps1`. На Linux подходит `исходники/export.py` с LibreOffice/UNO.

Проверка: `исходники/validate.py`; для PDF нужен `pdftotext` либо `pypdf`. Результат: `Результат_проверки.json`. Проверяется согласованность документов и моделей, а не работа реализованной ИС.

Предыдущие DOCX и PDF сохранены в `before_update.zip`.
