# Перенос в Process Modeler

AllFusion Process Modeler r7 использован для импорта и сохранения контекста IDEF0: `исходники/ProcessModeler/SmartCoworking_context.bp1`. Один блок, 14 стрелок, русский набор символов шрифта; штамп, заголовок и цветовое оформление отключены. Рядом сохранён XML обмена.

Перенос остальных 21 схемы в собственный формат редактора пока не подтверждён. При пакетном импорте DFD редактор сообщил об ошибке обработки данных. Такие файлы исключены из итогового архива. IDEF1X требует отдельного ERwin Data Modeler.

Для продолжения нужны общая декомпозиция IDEF0 A0, шесть процессов DFD с восемью накопителями и восемь сценариев IDEF3. Состав объектов и направлений приведён в отчёте. После сохранения каждый проект нужно повторно открыть и проверить связи, кириллицу и экспорт. Полное выполнение этого этапа в текущем комплекте не заявляется.

Схемы отчёта оформлены без внешних рамок по пожеланию пользователя. Границу листа на рабочем поле редактора следует отличать от штампа IDEF0.
