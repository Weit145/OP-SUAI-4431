# Sentinel Vision

Веб-приложение для анализа снимков Sentinel-2. Backend на FastAPI рассчитывает
спектральные индексы и сразу возвращает PNG-карты и статистику. Отдельный
frontend-контейнер на Nginx принимает загрузки и показывает ответ API.

Классификация пороговая и объяснимая: нейросеть не используется.

## Запуск в Docker

Требуется Docker с поддержкой Compose.

```powershell
Copy-Item .env.example .env
docker-compose up --build
```

Если установлен `make`, то те же контейнеры можно собрать и запустить командой:

```powershell
make up
```

Остальные команды можно посмотреть через `make help`.

После запуска доступны:

- веб-интерфейс — <http://localhost:8080>;
- Swagger — <http://localhost:8080/docs>;
- проверка состояния — <http://localhost:8080/_info>.

Остановка:

```powershell
docker-compose down
```

Приложение не сохраняет результаты. Входные файлы находятся во временной папке
только во время запроса и автоматически удаляются после формирования ответа.

## Режимы анализа

### NDVI

Загрузите два канала одной сцены:

- `B04` — красный;
- `B08` — ближний инфракрасный.

Поддерживаются JP2, TIF и TIFF. Результат делится на четыре уровня растительности.
Backend автоматически приводит каналы к общей рабочей сетке.

### Полная классификация

Загрузите ZIP продукта Sentinel-2 SAFE с каналами `B02`, `B03`, `B04`, `B08`,
`B11` и `B12`. Каналы с разрешением 10 и 20 метров автоматически приводятся к
общей рабочей сетке. Полные гранулы обрабатываются в ограниченном разрешении,
чтобы анализ не исчерпывал оперативную память. Результат содержит воду, открытую
почву, застройку, три уровня растительности и прочую поверхность.

XML-калибровка и маска SCL не используются.

## Результаты

POST возвращает JSON со статистикой, кратким описанием и полем `previews`.
Каждое изображение передаётся как Data URL `data:image/png;base64,...`, поэтому
frontend отображает карты без дополнительных запросов и файлового хранилища.

## API

Основные маршруты:

| Метод | URL | Назначение |
|---|---|---|
| `POST` | `/api/v1/analyses/ndvi` | анализ B04 + B08 |
| `POST` | `/api/v1/analyses/multispectral` | анализ ZIP сцены |

Точный multipart-контракт и интерактивные запросы доступны в Swagger.

## Архитектура

```text
app/
├── core/                  конфигурация и логирование
├── domain/                модели, индексы и правила классификации
├── usecase/               сценарии анализа и pipeline
├── infrastructure/        ZIP, Rasterio и визуализация
└── transport/api/v1/      FastAPI handlers и Pydantic schemas
frontend/                  HTML, CSS, JavaScript и Nginx
Dockerfile                 образ backend
docker-compose.yml         запуск backend + frontend
```

Поток зависимостей: `transport → usecase → domain`; временная работа с файлами и
растрами вынесена в `infrastructure`. PostgreSQL, RabbitMQ, файловое хранилище и
фоновые worker-процессы не используются.

## Настройки

Параметры читаются из `.env`:

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `APP_PORT` | `8080` | внешний порт интерфейса |
| `LOG_LEVEL` | `INFO` | уровень логирования backend |
| `MAX_UPLOAD_SIZE_MB` | `2048` | лимит одного загружаемого файла |

Для обработки полной гранулы Sentinel-2 Docker должен иметь достаточно оперативной
памяти: несколько каналов одновременно приводятся к общей сетке и хранятся как
массивы `float32`.
