# Классификация снимков Sentinel-2

Учебный Python-проект для анализа спутниковых снимков. Он рассчитывает спектральные
индексы и по понятным пороговым правилам выделяет воду, открытую почву, застройку и
растительность.

Это не нейросеть: каждый класс можно объяснить формулой и условием в коде.

## Что умеет проект

Есть два режима:

| Режим | Входные данные | Результат |
|---|---|---|
| Простой | `B04` + `B08` | NDVI и 4 уровня растительности |
| Полный | `B02`, `B03`, `B04`, `B08`, `B11`, `B12` | вода, почва, здания и 3 уровня растительности |

Работать можно через веб-интерфейс Streamlit или командную строку.

## Быстрый запуск

Требуются Python 3.10–3.13 и Poetry 2.

```powershell
cd vegetation-classification
poetry install
poetry run streamlit run app.py
```

После запуска откройте `http://localhost:8501`.

В интерфейсе:

1. Выберите режим.
2. Загрузите два канала или ZIP продукта Sentinel-2.
3. Нажмите **«Обработать»**.
4. Посмотрите карты и таблицу статистики.

Остановить сервер можно сочетанием `Ctrl+C`.

## Быстрая проверка на демо

Следующие команды создают шесть маленьких учебных GeoTIFF и запускают полный анализ:

```powershell
poetry run python download_data.py --demo
poetry run python main.py --product data/raw
```

Главный результат появится в `results/classified_map.png`.

### Где что выполняется

| Файл | Простое объяснение |
|---|---|
| `app.py` | Показывает форму, принимает файлы и выводит результат в браузере. |
| `main.py` | Принимает аргументы терминала и запускает ту же обработку. |
| `satellite/archive.py` | Находит нужные каналы внутри ZIP и копирует только их. |
| `satellite/bands.py` | Находит каналы в распакованной SAFE-папке. |
| `satellite/calibration.py` | Читает коэффициенты из XML Sentinel-2. |
| `satellite/raster.py` | Читает растры и приводит каналы 10/20 м к общей сетке. |
| `processing/indices.py` | Содержит все формулы спектральных индексов. |
| `processing/classification.py` | Применяет пороги и считает долю каждого класса. |

```text
app.py или main.py

        ↓
processing/indices.py — рассчитать индексы
        ↓
processing/classification.py — назначить классы
        ↓
pipeline.py — сохранить GeoTIFF, PNG, CSV и TXT
```

## Как работает алгоритм

1. Программа находит нужные каналы Sentinel-2.
2. Каналы приводятся к общей сетке. Для полного режима используется сетка `B11` с
   разрешением 20 м.
3. Если присутствует `SCL`, облака, тени и снег исключаются.
4. Рассчитываются спектральные индексы.
5. Пороговые правила присваивают каждому пикселю итоговый класс.

### Спектральные индексы

| Индекс | Формула | Что показывает |
|---|---|---|
| NDVI | `(B08 - B04) / (B08 + B04)` | растительность |
| NDWI | `(B03 - B08) / (B03 + B08)` | воду |
| MNDWI | `(B03 - B11) / (B03 + B11)` | воду с отделением от застройки |
| NDBI | `(B11 - B08) / (B11 + B08)` | застройку |
| BSI | `((B11 + B04) - (B08 + B02)) / ((B11 + B04) + (B08 + B02))` | открытую почву |
| UI | `(B12 - B08) / (B12 + B08)` | городские поверхности |

### Основные правила классификации

Пороги находятся в начале `src/processing/classification.py`, поэтому их легко менять.

| Класс | Главное условие |
|---|---|
| Вода | `MNDWI > 0.10`, `NDWI > 0.05`, `NDVI < 0.20` |
| Застройка | `NDVI < 0.20`, `NDBI > 0.05`, `UI > 0` |
| Открытая почва | оставшийся пиксель с `BSI > 0` |
| Слабая растительность | `0.20 <= NDVI < 0.40` |
| Средняя растительность | `0.40 <= NDVI < 0.60` |
| Густая растительность | `NDVI >= 0.60` |

Правила применяются по порядку: вода → растительность → застройка → почва → прочее.

## Входные данные

### Через Streamlit

- Для NDVI загрузите отдельно `B04` и `B08` в формате JP2/TIF/TIFF.
- Для полной классификации загрузите ZIP одной гранулы Sentinel-2 с шестью каналами.
- Канал `SCL` и XML-метаданные необязательны, но используются автоматически.

Настройку **BOA offset** в простом режиме оставляйте включённой для исходных JP2 из
современного Sentinel-2 L2A. Для уже откалиброванных GeoTIFF её нужно отключить.

### Через командную строку

Распакованный продукт или папка с шестью каналами:

```powershell
poetry run python main.py --product data/raw
```

Только B04 и B08:

```powershell
poetry run python main.py --red data/raw/B04.tif --nir data/raw/B08.tif
```

Шесть файлов можно указать явно:

```powershell
poetry run python main.py `
  --blue data/raw/B02.tif `
  --green data/raw/B03.tif `
  --red data/raw/B04.tif `
  --nir data/raw/B08.tif `
  --swir1 data/raw/B11.tif `
  --swir2 data/raw/B12.tif
```

Все параметры можно посмотреть командой:

```powershell
poetry run python main.py --help
```

## Получение реального фрагмента Sentinel-2

`download_data.py` умеет найти малоблачную сцену и скачать небольшой фрагмент:

```powershell
poetry run python download_data.py `
  --bbox 30.20 59.96 30.38 60.05 `
  --datetime 2024-06-01/2024-08-31 `
  --cloud-cover 20
```

Для этой команды требуется интернет. Режим `--demo` работает без интернета.

## Результаты

В `results/` сохраняются:

- `classified_map.png` — итоговая карта классов;
- `ndvi_map.png` — карта NDVI;
- `water_index_map.png` — карта MNDWI в полном режиме;
- `built_up_index_map.png` — карта NDBI в полном режиме;
- `class_statistics.csv` — количество и процент пикселей каждого класса;
- `result_summary.txt` — краткий текстовый отчёт.

В `data/processed/` сохраняются геопривязанные GeoTIFF с индексами и классификацией.

## Какие проверки оставлены

Код намеренно не перегружен валидацией. Оставлены только практические проверки:

- присутствуют необходимые каналы;
- в ZIP или папке выбрана одна гранула;
- выбранные файлы ZIP не имеют аномального размера;
- растры можно прочитать и совместить по геопривязке.

## Как коротко объяснить проект

> Программа принимает каналы Sentinel-2. Сначала Rasterio читает и совмещает их,
> затем NumPy рассчитывает NDVI и другие индексы. По значениям индексов простые
> пороговые правила определяют воду, почву, застройку и растительность. Pipeline
> сохраняет GeoTIFF и статистику, а Streamlit показывает результат в браузере.

## Ограничения

- Пороговая классификация может путать почву, бетон и светлые крыши.
- Пороги желательно настраивать под регион, сезон и конкретный снимок.
- Без `SCL` облака и тени не удаляются автоматически.
- Для точной оценки результат нужно сравнивать с эталонными данными.
